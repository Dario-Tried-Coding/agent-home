# Agent Home

Agent Home is the personal hub for launching agent sessions and maintaining shared guidance for work across repositories.

## Language

**Scope**

The boundary within which a set of agent-facing guidance applies.

**Agent Home scope**

The scope of personal working agreements and reusable guidance maintained in Agent Home. Reusable guidance can have its own conditions of applicability.

**Repository scope**

The scope of guidance that applies across one work repository.

**Nested scope**

A scope within a work repository that applies to a specific app, package, module, or other subtree.

**Entry file**

The file an agent uses to enter a scope and find the guidance that applies there.

**Canonical entry file**

The entry file that owns a scope's shared routing instructions.

**Client-specific entry file**

An entry file for a particular agent client. It can point to the same canonical guidance used by other clients.

**Work directory**

A local directory registered as a regular destination for work from Agent Home. It can have a configured scope as an entry directory.

**Reference directory**

A local directory registered primarily for consultation. A task can also target it directly for work.

**Repository routing**

The selection of a directory, its checkout when applicable, and the guidance for the task.

**Scope setup**

The entry files, glossary, and applicable guidance and decision records that support working within a scope.

**Configured scope**

A scope whose setup gives each supported client a working entry and a path to its applicable guidance.
