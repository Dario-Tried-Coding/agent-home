# Issue Tracker

Identify which project owns the issue. Use that project's tracker destination in `workspace.local.md` when configured. Otherwise follow its repository guidance when it declares a tracker. For issues about Agent Home itself, use its dedicated entry in `workspace.local.md`.

Resolve the destination before performing tracker operations. When the destination is missing or ambiguous, ask which tracker owns the issue. Resolve a relative scratch path from the scope that declares it, or from the work directory's entry directory for a local setting. Use the work directory itself when it has no entry directory.

When local Markdown is selected, follow the [local Markdown workflow](local-markdown.md) for ticket layout, updates, and Wayfinder. When a hosted tracker is selected, use its configured project and the corresponding tracker operations. For operations that use triage roles, read [triage labels](../triage-labels.md).
