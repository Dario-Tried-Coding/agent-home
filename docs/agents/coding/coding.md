# Coding

- Use [readability](code-quality/readability.md) for ownership, names, abstractions, control flow, and test placement decisions.
- When changing a stateful owner or resource lifecycle, read [stateful engines](stateful-engines.md). For an imperative core with observable snapshots, especially one built with XState or TanStack Store, read [observable cores](observable-cores.md).
- For TypeScript typing, runtime vocabularies, and type ownership, read [TypeScript](code-quality/typescript.md). For TypeScript-specific local construction and guards, read [TypeScript readability](code-quality/typescript-readability.md).
- When writing or reviewing React, start with the [React guide](react/react.md) and follow the relevant topic pointers.
- For Java or Spring, read [Java and Spring](code-quality/java.md) when changing types, injection, validation, configuration, or tests around those boundaries.
