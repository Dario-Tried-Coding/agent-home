# React Rendering

Read this when implementing or reviewing React rendering optimizations.

## Subscriptions

When writing or reviewing React subscriptions, selector hooks,
`useSyncExternalStore`, Zustand stores, custom observable stores, controller or
hub subscriptions, form-store subscriptions, or render-performance-sensitive
state reads, read [subscriptions](subscriptions.md).

## Verification

When implementing or reviewing an optimization intended to reduce unnecessary
renders, including selector migrations or subscription moves, read
[verification](verification.md).
