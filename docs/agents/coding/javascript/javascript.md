# JavaScript Ecosystem

- For implementation, reorganization, or review of TypeScript files (`.ts`, `.tsx`, `.mts`, or `.cts`), read the required foundations in [TypeScript](typescript/typescript.md), including when changing behavior, tests, or configuration.
- When choosing or changing the model of a stateful workflow, read [XState](xstate.md).
- When organizing a React application's source tree or writing or reviewing React components, subscriptions, rendering, or component-owned lifecycles, start with [React](react/react.md).
