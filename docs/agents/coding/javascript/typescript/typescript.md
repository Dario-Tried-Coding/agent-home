# TypeScript

For every TypeScript implementation, reorganization, or review, read both:

- [Types](types.md): type ownership, sources of truth, runtime vocabularies, and compile-time relationships.
- [Readability](readability.md): naming, API organization, local construction, and guards.

These are required foundations for TypeScript work, including behavior changes,
tests, and configuration. Apply them to the final change as well as its initial
design.
