# Triage Labels

Resolve the issue tracker first. Apply the mapping associated with that tracker, using the same source that selected its destination. For a local Markdown tracker using the standard roles, the status strings are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`.

For a hosted tracker, use the configured label for each role. If an operation requires a label whose mapping is missing, confirm that role's label before applying it.
