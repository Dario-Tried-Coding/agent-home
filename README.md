# Agent Home

Start Codex or Claude Code in this directory to load your shared working guidance and route work to a local checkout.

On each machine, copy `workspace.example.md` to `workspace.local.md` and record your work and reference directories. Use paths relative to this directory or absolute paths. For a repository with a configured scope below its Git root, record that entry directory relative to the checkout. Configure a tracker only where you need to choose a destination locally.

Name the directory or project in your task. Add the worktree name or branch when you want a specific checkout. See [repository routing](docs/agents/repository-routing.md) for the lookup order and [scope setup](docs/agents/scopes.md) for project guidance.
